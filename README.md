Для работы нужен файл env.json. В котором нужно указать TOKEN и OPERATOR, например

{

  "TOKEN": "token777",
  "OPERATOR": "@Yaroslav9605"
  
}

Для работы нужен файл admins.json. В котором указаны ID админов, например

{

  "admins": [
    "1075907948",
    "1264725550"
  ]
  
}

Для работы нужен файл faq_data.json. В нем указываются пары вопрос ответов, пример прилагается.
Файл логов так или иначе появляется во время работы, в них сохраняется информация о работе с админ панелью, 
случаи, когда бот не находит подходящей пары вопрос-ответ из базы вопросов и ответов, а также обратная связь.

Хостить можно локально без ngrok, но мы для хостинга используем AMVERA, 
вся работа с файлами, в том чисел добавление/удаление вопросов сохраняется либо локально, либо в Artifacts в AMVERA.
Для хостинга требуется для стабильной работы 2 GB ОЗУ, 0,5 CPU, а также файл requirements.txt. Порт не важен.
